# flash-ADC
# Flash ADC — StrongARM Latch Comparator & CMOS Priority Encoder

3-bit Flash ADC designed in 180 nm CMOS, using a StrongARM dynamic
latch comparator array driven by a resistor-ladder reference and a
CMOS (NAND-only) priority encoder that converts the thermometer code
to binary.
---

## 1. Overview

A Flash ADC is the fastest ADC architecture — conversion happens in a
single clock cycle. An array of comparators simultaneously compares
`Vin` against a set of reference voltages generated by a resistor
ladder, producing a **thermometer code**. A priority encoder then
converts this into a binary output.

```
Vin ──► [Comparator array] ──► Thermometer code ──► [Priority Encoder] ──► Binary out (B2 B1 B0)
              ▲
        Vref ladder
```

- **Resolution:** 3-bit → 7 comparators, 8 resistor-ladder taps
- **Comparator:** StrongARM dynamic latch (fully dynamic, no static power)
- **Encoder:** built entirely from 2-input NAND gates (see [Design Decisions](#5-design-decisions))
- **Process:** 180 nm CMOS, VDD = 1.8 V

## 3. Transistor Sizing

### StrongARM Comparator (W/µm, L = 0.18 µm)

| Transistors | Function                          | W (µm) |
|-------------|------------------------------------|--------|
| M1, M2      | Input NMOS pair                    | 2.0    |
| M3, M4      | Regenerative NMOS (latch)          | 5.0    |
| M5, M6      | Regenerative PMOS (cross-coupled)  | 12.0   |
| M7          | Tail / clock NMOS                  | 4.0    |
| S1–S4       | Clock / pass transistors           | 3.0    |

### CMOS Logic Gates (encoder)

| Device               | W (µm) | L (µm) | W/L  |
|-----------------------|--------|--------|------|
| Logic NMOS (typical) | 0.54   | 0.18   | 3.00 |
| Logic PMOS (typical) | 1.08   | 0.18   | 6.00 |

## 4. Resistor Ladder

## 5. Design Decisions

- **Why StrongARM latch:** fully dynamic → no static power, fast
  positive-feedback regeneration, simple topology that scales well
  for large comparator arrays.
- **Why only 2-input NAND gates in the encoder:** larger (3-/4-input)
  gates create long transistor stacks that increase delay, can fail
  to drive full logic levels, and load the comparator outputs enough
  to disturb StrongARM regeneration. 2-input NANDs give faster
  switching, better noise margins, and simpler sizing.

## 6. Verification

Simulated cases (see `results/waveforms/`):
- Static `Vin` = 1.6 V, 1.4 V, 0.9 V (DC codes vs. clock)
- Sine-wave input, `Vdc = 0.8 V`, amplitude = 0.8 V
- Full thermometer-to-binary truth table (`results/truth_table.csv`)

Known non-ideality: brief glitches at code transitions due to
comparator mismatch/regeneration-delay skew and StrongARM kickback
noise — these settle out once all comparators resolve.
